# Salvador

Modelo fornecido pelo usuário: `salvador_bahia_3d.obj`, copiado como `salvador.obj`.
25 objetos, 30.094 vértices e 58.504 triângulos. O OBJ original não contém UVs ou referências a materiais.

O aplicativo preserva a geometria e aplica cores próprias por altura e objeto. Os pontos turísticos são âncoras ilustrativas; o OBJ não contém coordenadas geográficas ou nomes individuais dos lugares. Não usar o modelo para estimar percursos reais. Licença do modelo não fornecida; a licença do Three.js não se aplica a ele.

Materiais de `salvador_3d_texturas_reais.zip` fornecidos pelo usuário: `salvador_bahia.mtl` e três PNGs. O aplicativo associa manualmente os materiais ao farol e aos casarões, gerando UVs para as fachadas e mantendo os telhados separados. A imagem de asfalto está incluída, mas não é aplicada: o modelo não possui uma malha de ruas identificável. O terreno e o mar mantêm a paleta por altitude.
